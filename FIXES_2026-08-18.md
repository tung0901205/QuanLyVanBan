# Các sửa đổi theo yêu cầu 18/08/2026

1. **Template văn bản**
   - Chọn tệp `.doc`, `.docx`, `.pdf`, `.odt`, `.rtf` trực tiếp từ máy tính.
   - File được upload vào Document Service và lưu trong Docker volume `document_uploads`.
   - **Tạo từ mẫu** tạo một văn bản Nháp; nếu template có file thì file được gắn làm tệp đính kèm của văn bản mới.

2. **Tài khoản**
   - Đã bỏ toàn bộ **Cài đặt thông báo** và phần Azure Active Directory mẫu.

3. **Luân chuyển văn bản**
   - Chọn người nhận nào thì **Đơn vị xử lý** tự động lấy đúng đơn vị của người đó và bị khóa, không thể chọn chéo phòng ban.
   - Backend kiểm tra lại quan hệ người nhận - đơn vị nên không thể sửa request để gửi sai phòng ban.
   - Văn bản trạng thái **Đã ban hành** không còn nút luân chuyển và backend cũng từ chối request luân chuyển.

4. **Phân quyền và giao diện Lãnh đạo**
   - Lãnh đạo có thêm **Quy trình xử lý**, **Template văn bản**, **Báo cáo & Thống kê**.
   - Bảng phân quyền có **Xem báo cáo thống kê** và quyền quản lý workflow/template cho `LANH_DAO`.
   - Admin không còn ba màn hình nghiệp vụ trên menu/route Admin; chỉ giữ các màn hình quản trị hệ thống.

5. **Dữ liệu cũ**
   - Migration `V008__manager_operations_template_and_cleanup.sql` dọn dữ liệu demo Azure SSO và đường dẫn template `/templates/...` không còn hợp lệ; giữ nguyên dữ liệu nghiệp vụ văn bản.

## Chạy lại

```powershell
docker compose down --remove-orphans
docker compose up -d --build
docker compose ps
docker compose logs db-migrations --tail=150
```

Không chạy `docker compose down -v` nếu muốn giữ dữ liệu PostgreSQL và file template đã upload.
